# Contexto
Las entregas deben llegar al ERP en menos de 5 minutos (RQ-04) y el ERP tiene ventanas de mantenimiento.

# Opciones consideradas
1. **Llamada directa a la API del ERP** — simple, pero se pierden entregas si el ERP está caído.
2. **Cola de mensajes intermedia** — tolera caídas del ERP; agrega un componente a operar.

# Decisión
Cola de mensajes intermedia con reintentos.

# Consecuencias
Mayor resiliencia; hay que monitorear la cola y definir qué pasa con mensajes que fallan repetidamente.
