# Glosario

| Término | Significado |
|---|---|
| ROE | Utilidad / patrimonio: rentabilidad sobre el capital de los accionistas |
| P/U | Precio / utilidad por acción |
| Deuda/EBITDA | Deuda financiera neta sobre EBITDA: capacidad de pago de la deuda |
| Drawdown | Caída desde el máximo previo |
| Sharpe | Retorno sobre la tasa libre de riesgo, dividido por la volatilidad |
| TWR | Retorno ponderado por tiempo: mide la gestión sin el efecto de aportes y retiros |
| IDX | Índice de referencia (ficticio) |
