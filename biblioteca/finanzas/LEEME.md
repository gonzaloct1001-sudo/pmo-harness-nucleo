# Biblioteca de finanzas

Material reutilizable para proyectos del arquetipo `finanzas`:

- `plan-de-cuentas-base.csv`: un plan de cuentas genérico ya mapeado a las líneas del reporte, para partir cuando la
  empresa no tiene uno o para ver cómo se mapea el suyo. Se copia al proyecto y se adapta; nunca se edita aquí.
- `kpi-definiciones.md`: qué mide cada indicador, cómo se calcula y cómo se lee.
- `paises/<pais>.md`: lo propio de cada país (impuestos, calendario tributario, norma contable, moneda de ajuste),
  como referencia para los supuestos y el calendario de cierre. **Siempre se confirma con el contador:** las tasas y
  los plazos cambian.

Los archivos que trae el núcleo se actualizan con él; los que agregue la empresa (otro país, su propio plan base)
se conservan.
