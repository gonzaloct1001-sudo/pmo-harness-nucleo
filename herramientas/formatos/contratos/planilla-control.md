# Secciones

Para una planilla, las «secciones» son sus hojas o sus columnas. Lo que no esté en la planilla no se reporta ahí.

| Sección | Sinónimos | Fuente en el harness | Obligatoria |
|---|---|---|---|
| Avance | hitos, cronograma, actividades, tareas, cumplimiento, físico | cronograma/, evm_cpm.py | no |
| Presupuesto | costos, gasto, financiero, montos, devengado, ejecutado | presupuesto/, evm_cpm.py | no |
| Riesgos | alertas, issues, problemas | riesgos/ | no |
| Indicadores | kpi, métricas, semáforo, resumen | metricas/mediciones.csv | no |
